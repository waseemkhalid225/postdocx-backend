ForiForeign API v1

Read access to your own organisation's data, and signed webhooks for events. Keys are created by an organisation owner under Workspace → Team → API keys. Send the key in the x-api-key header. All responses are JSON. Base URL: https://foriforeign.com.

Endpoints

Method · PathReturns
GET /api/v1/clientsYour clients: id, name, contact, lane, journey stage, branch, timestamps (max 200, newest first).
GET /api/v1/openingsYour posted openings (institutions/employers): title, kind, country, deadline, status.
GET /api/v1/applicantsApplications to your openings. Applicant identity appears only after the applicant consents.

Webhooks

Created under Workspace → Team → Webhooks. Each delivery is a POST with JSON body and these headers: x-ff-event, x-ff-delivery, x-ff-signature (sha256= + HMAC-SHA256 of the raw body using your webhook secret). Reply 2xx within 10 seconds; failures retry with backoff up to 5 times.

// Node.js verification
const crypto = require('crypto');
function verify(rawBody, header, secret) {
  const expected = 'sha256=' + crypto.createHmac('sha256', secret).update(rawBody).digest('hex');
  return header.length === expected.length && crypto.timingSafeEqual(Buffer.from(header), Buffer.from(expected));
}

White-label

Owners can attach their own domain under Workspace → Team → Domain. Add a DNS TXT record _foriforeign.yourdomain.com with the token shown, point the domain (CNAME) at foriforeign.com, and verify. Visitors on your domain see your name, colour and logo; people who sign up there become your clients.

Rate limit: 600 requests per hour per key. Questions: admin@foriforeign.com
